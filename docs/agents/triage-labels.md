# Triage Labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Request needs initial analysis and classification. |
| `needs-info` | Progress is blocked until the requester provides information. |
| `ready-for-agent` | Scope and acceptance criteria are clear enough for implementation. |
| `ready-for-human` | A product, security, legal, or operational decision is required. |
| `wontfix` | The request is explicitly out of scope or will not be implemented. |

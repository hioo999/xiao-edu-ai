## 第一阶段实现记录

### 权限规则

- 教师只能读取任教班级的课堂详情、学生目录、学习报告、学习进度与作业。
- 学生目录先按任教班级过滤，再分页；指定未授权班级直接拒绝。
- 教师只能向任教班级批量开户，不能借助同机构权限向其他班级开户。
- 教师可以管理本人作品及当前任教班级学生作品；非任教班级已审核的机构公开作品只读，不因此获得编辑或审核权限。
- 作品详情、文件下载、媒体、互动、审核、元数据、工程部署接口校验同一资源权限。
- 批量审核先校验整个请求，遇到越权或不存在的作品不执行前面作品的审核。
- 教师只能修改自己编写的课程；可阅读本人课程和发布到任教班级的课程。管理员修改课程时保留原作者。
- 课程发布、撤回需要校验目标班级；课件下载和删除分别校验课程读写权限。
- 学生课程响应不包含教师逐字稿；教师响应仍保留。
- 生成任务监控和人工重试限制任教范围；机构管理员的死信查询与重试不得越过机构。
- 教师创建、撤销其他人作品分享时校验作品归属，不再只校验角色。
- 课堂协助要求学生确实属于该班；学生不能在其他班级上报在线状态。
- 教师只能编辑自己的教师知识库和自己课程的知识资料；机构公共知识由管理员维护。教师不能浏览其他教师或学生的私人知识资料。
- 文字生成检索知识库时按调用者过滤；伪造未授权课程上下文在调用模型之前拒绝。

### 验证入口

```sh
python -m pytest tests/unit/test_teaching_access_policy.py tests/integration/test_teaching_access.py tests/integration/test_knowledge_grounded_generation.py tests/e2e/test_teaching_operations.py -q
python -m pytest -q
cd apps/web && npm test && npm run test:e2e
```

- 单元测试：角色、机构、任教范围、未配置依赖时拒绝、教师重新分配后立即撤权。
- 集成测试：正常与越权 HTTP 请求、批量操作无越权副作用、私有知识不进入模型上下文。
- HTTP E2E：管理员创建老师和班级、批量开户、教师开课发布课程、学生提交作品、教师点评、管理员审核展示、换老师后撤权。
- 浏览器 E2E：运行既有 Playwright 回归；HTTP E2E 不等同于真实浏览器验证。
- 模型冒烟：内置确定性模型协议烟测通过；真实轻量模型测试未配置而跳过，不能据此声称真实模型加载通过。本阶段没有调用收费供应商。

### 第一阶段文件收尾与后续边界

- 本地生成文件的匿名静态挂载已移除；参考图、生成媒体、Range/HEAD、分享撤销、路径和符号链接防护均已补齐，并同步适配学生端预览与下载。详见 `docs/generated-file-access.md`。
- 反向代理不能绕过 API 暴露私有目录；COS/CDN 私有访问和真实部署验证不属于已完成的本地文件验证结果。
- 与第二阶段成员历史衔接：确定转班前后课堂记录、作品、任务的授权快照；在此之前权限以当前班级为准。
- 当前本地部署的权限阶段通过回归，可以进入第二阶段；不将全量自动化测试通过当作所有部署形态的生产安全认证。

## 后续必须明确的边界

- 当前作品教学权限仍按学生当前班级判定。历史作品归属与转班快照应在第二、三阶段完成，不能当成已经支持历史班级隔离。
- 当前课堂协助接口返回授权和界面状态，不代表已经实现完整远程屏幕或代操作。
- 本阶段不把消费次数额度当作完整积分钱包；多层预算及交易账本由第四阶段交付。
- 文件存储地址的访问生命周期、外链过期和内容版本审核属于后续作品运营与安全验收。
- SQLite 继续单机部署；本次测试不证明多实例一致性或千人同时生成的容量。
- 真实 API、MCP、收费音视频和外部基础设施验收单列，不用模拟测试替代。

# 教师账号生命周期与教学交接

## 本批范围

完成教师及机构管理员账号的专用安全操作入口，以及教师班级、课程的交接。保留 SQLite，不改变原有后台视觉体系。

后台入口：账号管理 → 对应工作人员的「管理账号」。教师面板包含教学资源清单、密码重置、强制下线、有效期、启停、离职交接和交接历史。

## API

以下接口均位于 `/organizations/{organization_id}/staff/{username}`：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/reset-password` | 重置工作人员密码，撤销旧会话和已有课堂协助授权 |
| PUT | `/state` | 启用或停用；仍有教学资源的教师需先交接 |
| PUT | `/expiry` | 设置或清除有效期 |
| POST | `/revoke-sessions` | 强制下线并清理已有协助授权 |
| GET | `/handover-plan` | 查看任教班级和负责课程 |
| POST | `/handover` | 移交全部当前班级和课程并停用原教师 |
| GET | `/handover-history` | 查看包含原因、操作者、接任者和资源清单的交接记录 |

交接请求字段为 `replacementUserId` 和 `reason`。接任者必须为本机构另一名已启用、未到期的教师；交接原因必填。

## 权限与状态规则

- 机构管理员只操作本机构；教师和学生不能调用上述管理接口。
- 此入口不能管理平台管理员，也不能对当前操作者自身执行这些管理动作。平台根账号恢复、个人自助修改密码不属于本批入口。
- 停用教师、将教师立即设为已到期之前，检查其是否仍有任教班级或负责课程。有则返回 409，不能留下无人负责的教学资源。
- 批量启停和批量有效期操作先检查全部已存在的目标，避免前面的账号先被修改，随后才因后面的账号违反交接规则而失败。批量账号写入本身尚不承诺跨账号数据库故障时整体回滚。
- 旧学生账号接口只处理学生，不再允许借学生路径修改工作人员或平台管理员。
- 已停用、已到期的教师不能重新分配为任课教师。
- 无时区的账号有效期按上海时间解释，再统一存为 UTC；带时区的值保持对应的真实时间点。工作人员创建、学生批量开户和有效期更新采用同一规则。
- 管理员页面日期控件按当前电脑的本地时间选择，再发送带时区时间。

## SQLite 事务边界

教学交接要求身份、课堂、课程及持久化审计使用同一个 SQLite 文件。

同一事务内完成：

1. 重新检查接任教师是否有效。
2. 把原教师的任教关系替换为接任教师，保留其他共同任课教师。
3. 转移原教师的课程维护人，保留课程内容、发布关系和课程 ID。
4. 停用原教师并删除其登录会话。
5. 写入持久化 `staff_handovers` 交接历史与审计事件。

提交后刷新账号、课堂和课程缓存，清理原教师已有协助授权。事务失败时不提前修改内存，班级、课程、账号、交接历史和事务内审计一起回滚。

密码重置、直接停用及立即到期，在 SQLite 下也将账号变化与登录会话删除放入同一事务。密码重置事务失败时旧密码和旧会话保持原状，不出现「新密码已生效但旧会话仍有效」的半成功状态。

课程保存、发布、撤回、删除、课件写入，以及班级创建、教师分配，与交接使用同一个进程内教学写锁。在写操作执行前重新检查账号状态，防止已经通过早期登录校验的停用教师请求在交接之后新增或修改教学资源。

## 保留与限制

- 学生作品、学生账号、作业与学习进度不转移所有者，也不删除。接任教师通过接任班级获得相应教学权限。
- 教师私人聊天、私人知识库、个人作品及其已受理的媒体生成任务，不在本批自动交接范围内；需要管理员按后续作品、任务运营规则处理。
- 允许为历史上已停用但仍遗留教学资源的教师补做交接。
- 未来到期的账号不会自动移交班级；到期提醒、代课安排和自动化运营仍待后续补齐。
- 当前实现支持同一 SQLite 文件及纯内存测试环境。混合数据库、独立数据库文件或 PostgreSQL 交接适配尚未实现，接口明确拒绝，不做跨库部分提交。
- 写锁属于单个 API 进程；不宣称支持 SQLite 多 API 实例、多进程的一致性交接。
- 班级成员历史、学生转班、主讲/助教/代课有效期仍是第二阶段后续任务。

## 验证

- `tests/unit/test_staff_lifecycle_rules.py`：角色、在内存中完整交接、保留共同任课教师、混合存储拒绝、时区和已停用管理员。
- `tests/integration/test_staff_lifecycle.py`：真实 SQLite 持久化、密码与会话回滚、课程/审计故障注入回滚、越权、批量绕过、旧接口绕过，以及交接后的延迟写请求。
- `tests/e2e/test_staff_teaching_handover.py`：真实 HTTP 下，管理员建老师和班级、学生保存作品、交接、接任教师查看点评、学生数据保留。
- `apps/web/tests/staff-lifecycle.test.ts`：专用客户端接口、编码、授权头与交接冲突反馈。
- `apps/web/e2e/staff-lifecycle.spec.ts`：浏览器管理面板、重置密码、交接确认、历史展示和窄屏布局。此浏览器用例模拟 API；真实事务由上述 SQLite 集成和 HTTP E2E 验证。

本批不调用收费模型，不以模拟测试替代真实云服务验收。

# 真 3D「AI 创作书」首页设计

## 目标

把学生首页的主入口升级为可交互的实时 3D 微缩世界：一本打开的 AI 创作书，书页长出地形，知识河从中缝流向前景，六栋建筑分别对应六种创作能力。学生点击建筑后直接进入对应创作页。

视觉基调为原创的童话玩具微缩世界：圆润、明亮、可亲近，不复制任何第三方页面的建筑、文字气泡、布局或素材。

## 场景与镜头

- **舞台**：浅天蓝天空、云层与少量星光；中心是一册横向打开的精装书。
- **书页地形**：左、右书页各自是起伏草地，保留纸页层叠的书本质感；中间书脊清晰可见。
- **知识河**：蓝绿色河水由书脊向前流出并落入云海，带低频流光、碎星和小桥。
- **镜头**：固定在 3/4 俯视等距角度；允许鼠标/手指引起小幅视差，禁止自由旋转、缩放和迷失方向。
- **首次进入**：书本展开 → 河流亮起 → 六栋建筑按河流两岸依次出现；总时长不超过 3 秒，跳过也不影响操作。

## 六个创作建筑

| 建筑 | 功能 | 目标路由 | 识别物 |
| --- | --- | --- | --- |
| 故事灯塔 | AI 对话 | `/workspace/chat` | 灯塔、星轨、发光书页 |
| 网页工坊 | 网页创作 | `/workspace/html` | 紫色工作台、浏览器窗、工具臂 |
| 画画花房 | 图片创作 | `/workspace/image` | 玻璃花房、调色板、画笔与花朵 |
| 音乐树屋 | 音乐创作 | `/workspace/music` | 大树、木屋、吉他与音符 |
| 影像剧场 | 视频创作 | `/workspace/video` | 小剧场、胶片盘、投影光束 |
| AI 伙伴学院 | 智能体中心 | `/agents` | 圆润机器人、蓝色学院屋顶、星徽 |

不在场景内放大块灰色标签或对话气泡。默认只以建筑造型帮助识别；鼠标悬停、键盘聚焦或触摸首次点按后，显示小型名称牌和“进入创作”。

## 交互

- 每栋建筑都有独立 3D 点击热区，鼠标悬停时门窗发亮、建筑轻微抬升、名称牌出现。
- 点击后锁定输入，镜头在 350–500ms 内向建筑推进，然后直接导航；用户设置“减少动态效果”时省略镜头动画。
- Tab 键按照左至右、上至下顺序聚焦六栋建筑；Enter 与空格执行同一跳转。
- 在触摸设备上，首次触摸显示名称与高亮，第二次触摸进入；下方保留普通二维入口卡片，作为无 WebGL 与辅助操作回退。

## 技术方案

- 使用 React Three Fiber、Three.js 与 Drei 渲染真实 3D 场景；模型采用轻量 GLB，纹理采用压缩 KTX2 或 WebP。
- 一个场景管理器只负责相机、光照、环境、载入状态和性能等级；书本、河流、建筑各自独立为可测试组件。
- 采用 raycasting 映射建筑点击，并在每栋建筑外提供隐藏但可聚焦的语义链接，避免 3D Canvas 成为唯一入口。
- 动画使用帧率自适应：低于目标帧率时先关闭阴影与粒子，再降低像素比；不影响建筑导航。
- WebGL 初始化失败、`prefers-reduced-motion`、窄屏或设备等级过低时，显示同一构图的静态视觉稿和六个普通链接；不出现空白区域。

## 资源与版权

- 当前已生成的视觉稿只用于方向确认，不直接作为最终页面素材或第三方品牌资产。
- 正式场景使用自制/商业可用的 GLB 模型、原创纹理与原创色彩系统；模型、纹理、字体分别记录许可证和来源。
- 绝不抓取或复用参考网站的截图、图片、3D 模型、名称、图标或代码。

## 性能目标与验收

1. 桌面课堂电脑的首屏在 4 秒内可操作，3D 场景在资源载入时显示明确骨架屏。
2. 常规设备稳定目标为 45 FPS；低性能设备能自动降级且仍可直接打开六个功能页。
3. 书本、河流和全部六栋建筑均可见；每栋建筑的视觉含义与路由表一致。
4. 鼠标、触摸、键盘和读屏器均可到达相同入口；不把文字信息仅放进 Canvas。
5. 无 WebGL、减少动态效果、网络慢和资源加载失败都不会阻断学习入口。

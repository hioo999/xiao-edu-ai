# Issue Tracker

## System

- Provider: GitHub Issues
- Repository: `hioo999/xiao-edu-ai`
- Default branch: `main`
- Pull requests are not the default requirements surface.

## Workflow

1. Record product requests and defects as GitHub Issues.
2. Add acceptance criteria before implementation.
3. Split larger issues into focused implementation tasks.
4. Link tests and verification results to the issue.
5. Close an issue only after the requested behavior is verified.

## Local constraint

The local checkout may be ahead of or separate from the remote repository. Do not push, commit, or rewrite remotes without explicit user authorization.

# 本地生成文件访问闭环

## 已实现

`/generated-assets` 不再是匿名静态目录，而是经过登录与资源权限校验的 GET/HEAD 接口。

| 文件 | 访问规则 |
| --- | --- |
| 任务生成的图片、音乐、视频 | 本人、当前机构管理员、任教班级教师可读取 |
| 已审核且机构可见的生成作品 | 当前机构已登录用户可读取 |
| 原始参考图 | 本人及当前机构管理员可读取；教师不因任教关系自动获得权限 |
| 无任务元数据的文件 | 不开放，即使知道文件名也不能读取 |
| 已审核作品的分享媒体 | 经过分享 Token 校验，链接失效、撤销或作品撤回审核后不再提供新请求 |

平台管理员的原始文件读取沿用当前机构上下文，不将文件地址作为跨机构入口。

## 安全约束

- 不在 URL 中传递登录令牌。
- 前端仅向配置的平台 API 发送 Authorization，外部媒体地址不附带令牌。
- 登录预览使用鉴权请求取得 Blob URL；组件卸载或资源变化时释放 Blob URL。
- 分享媒体通过 `/shares/public/{token}/media/{slot}` 提供，不暴露可绕过撤销的本地原始文件入口。
- 分享读取同时验证任务、作品、作者和机构的对应关系，防止伪造作品元数据引用他人的文件。
- 路径穿越、身份字段包含目录分隔符、目录/文件符号链接均拒绝。
- 文件响应采用媒体类型白名单、nosniff、禁止缓存及受限 CSP；不通过此接口执行上传的 HTML 或服务器代码。
- 支持授权的 Range 请求及 HEAD；跨域预检允许 Authorization 和 Range。

## 兼容性

- 本地 Worker 仍保存已有格式的 URL，无需批量修改数据库里的旧 URL。
- 首页作品墙、作品详情、创作小屋、智能体结果、我的作品和我的素材均通过安全预览适配器读取本地媒体。
- 本地开发兼容相同协议、端口下的 localhost 与 127.0.0.1；不将其他主机或其他端口当作平台 API。
- 支持平台 API 部署在 `/api` 等反向代理前缀下。
- 前后端必须一起发布。旧前端缓存若仍直接引用未鉴权文件，应刷新到新版本，不能为兼容旧页面重新开放匿名目录。

## 部署边界

1. 反向代理必须将 `/generated-assets` 转发到 FastAPI，不能再配置 Nginx alias、公开静态目录或公开 CDN 回源旁路。
2. `GENERATED_ASSET_STORAGE_PATH` 只作为私有文件存储目录；API 和本机 Worker 使用同一目录。
3. `PUBLIC_API_BASE_URL` 与前端 `NEXT_PUBLIC_API_BASE_URL` 应指向同一个 API 服务及代理前缀。
4. 该实现保护当前 SQLite 单机方案下的本地文件。已有第三方媒体 URL 或公开 COS/CDN URL，不会因为本平台接口加了鉴权就自动变成私有。
5. 若启用 COS，应另行完成私有桶、受控读取或短期签名链接及撤销策略的适配和真实环境验证；本次不宣称 COS 私有访问已交付。
6. 撤销分享能阻止后续请求，但不能收回用户此前已保存的字节或截图。
7. Blob 预览会先读取文件；长视频流式鉴权及缩略图优化保留为后续容量优化，不把当前测试当作千人并发证明。

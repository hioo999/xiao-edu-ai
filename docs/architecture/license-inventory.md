# License Inventory

The commercial release must record every dependency, version, license, attribution requirement, model-weight term, and trademark restriction.

## Initial Policy

- Prefer MIT, Apache-2.0, BSD, and similarly permissive dependencies.
- Review GPL, AGPL, SSPL, BUSL, non-commercial, research-only, and model-specific terms before adoption.
- AgentScope and every provider SDK require a release-time license review.
- Keep this inventory synchronized with lockfiles and container images.

# 后台 UI 设计审查

日期：2026-10-28

范围：管理员后台 `/admin/*`、教师后台 `/teacher/*`、后台共享样式和登录后的状态反馈。

## 审查结论

后台已经具备统一的浅色运营控制台视觉：导航、页面标题、面板、指标卡和按钮使用同一套颜色变量与圆角语言，桌面端和窄屏端也有明确断点。当前主要问题集中在信息密度和任务聚焦，而不是基础样式缺失。

## 8 个维度

| 维度 | 结论 | 优先级 |
|---|---|---|
| 字体排版 | 层级清楚，标题和说明对比足够；导航描述在窄屏隐藏后仍可识别。 | P2 |
| 留白节奏 | 面板、指标卡和页面标题间距一致；部分配置页内容较长，首屏缺少摘要。 | P2 |
| 视觉层级 | 首页有指标、运行状态、课堂和快捷操作；服务商配置页的预设列表、编辑器和调用记录竞争注意力。 | P1 |
| 色彩系统 | 后台已从旧深色教师样式覆盖到白色运营台，紫蓝主色统一；状态颜色需要避免“硬编码正常”。 | P1 |
| 动效 | 导航和按钮有轻量过渡，并支持减少动效；后台缺少加载完成和保存成功的连续反馈。 | P2 |
| 微交互 | 有 active、focus、折叠菜单和状态提示；危险操作的确认和完成后的定位仍可加强。 | P2 |
| 响应式 | 820px 断点将侧栏变为横向导航，表格允许横向滚动；后台导航项目较多，移动端仍需较多滑动。 | P1 |
| 原创性 | “星芽 AI”品牌、浅色学习运营台和课程/作品数据混合布局有辨识度；服务商配置页仍偏通用控制台。 | P2 |

## 已修复

- 后台顶部的“系统运行正常”不再是固定文案，改为读取 `/health/ready`：检查中、正常、服务异常三种状态。
- 服务异常状态使用明确的红色提示，避免后台人员误以为模型或 API 可用。

## 下一轮建议

1. 将后台导航改为“常用任务 + 全部功能”，默认收起低频的 MCP、Skills、审计等项目。
2. 服务商页首屏先展示当前主模型、备用模型、最近一次调用和连接状态，再展开完整服务商目录。
3. 统一保存、删除、发布、撤回等操作的反馈位置，避免反馈出现在页面底部导致用户找不到结果。
4. 为移动端后台增加固定的当前模块标题和横向导航定位，降低多组导航横向滑动成本。

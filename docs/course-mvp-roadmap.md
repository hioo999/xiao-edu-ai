# 星芽 AI 创作岛：课程 MVP 排期

## 目标

完成教师上传课程、课件和逐字稿，学生学习课程并记录进度，管理员审核发布；保留现有 Token 积分配额控制，统一积分展示与扣减规则。

## 第一阶段：课程数据与权限

- 课程、章节、课时、课件、逐字稿的关系整理
- 教师只能管理自己有权限的课程
- 逐字稿默认仅教师和管理员可见
- 课程草稿、待审核、已发布、已下架状态
- 文件类型、大小和上传安全校验

## 第二阶段：教师端课程工作流

- 创建和编辑课程
- 创建章节和课时
- 上传课件
- 上传逐字稿
- 调整顺序
- 预览学生视图和教师视图
- 保存草稿、提交审核、发布和下架

## 第三阶段：学生端学习闭环

- 课程列表和我的课程
- 课程详情、章节和课时
- 课件查看/下载
- 逐字稿不对学生开放
- 自动记录学习进度
- 继续学习
- 课程与作品入口关联

## 第四阶段：积分与 Token 收口

- 保留现有 student/class/organization/platform 配额层级
- 保留 reserve/finalize/release 防止重复扣费
- 统一文本、图片、视频、音乐的扣费入口
- 增加“我的积分”展示和管理员额度配置
- 明确课程使用 AI 工具时的扣费归属：学生优先，其次班级，最后组织
- 增加余额不足的中文提示和审计记录

## 暂缓

家长端、复杂学生管理、排课、请假、支付结算、赛事、小组协作、教育局端。

## 验收闭环

教师登录 → 创建课程 → 上传课件和逐字稿 → 提交审核 → 管理员发布 → 学生进入我的课程 → 查看课件 → 自动记录进度 → 使用 AI 工具按规则扣除 Token。

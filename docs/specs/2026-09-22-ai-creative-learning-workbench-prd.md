# AI 创造力学习工作台 PRD

## 1. 文档信息

- 产品名称：AI 创造力学习工作台
- 文档类型：产品需求文档（PRD）
- 版本：v0.1
- 日期：2026-09-22
- 目标用户：小学 3–6 年级学生、教师、学校/培训机构管理员、平台管理员
- 首期规模：约 60 名学生，按 100 人以内同时在线设计
- 首期部署：腾讯云中国大陆区域
- 商业目标：先服务自有课程，架构预留多机构 SaaS 和后续商业化能力

## 2. 产品定位

本产品是一个面向小学 3–6 年级的多模态 AI 智能体工作台。学生只需使用平台分配的账号登录，即可在统一平台内使用文字、网页、图片、音乐、视频和语音能力，不需要注册或登录豆包、WorkBuddy 等第三方工具。

产品不是第三方工具聚合登录系统，也不依赖绕过第三方登录、共享第三方账号或非官方接口。WorkBuddy 仅在架构中预留未来官方授权接入位置，首期不实现实际集成。

AgentScope 是从 GitHub 获取的智能体底座，负责智能体运行、工具调用和协作编排；本产品在其上建设面向学生的完整产品体验、课程体系、作品系统和多模态工作台。

核心价值：

1. 用 3D 场景降低小学生进入 AI 工具的门槛。
2. 用自然语言 Vibe Coding 生成网页和交互作品。
3. 用课程、教学流程和 AI 引导把“生成结果”转化为学习过程。
4. 用统一模型网关屏蔽国内外模型差异。
5. 用机构、班级、学生隔离和教师课堂控制保障教学安全。
6. 用灵感案例降低学生面对空白输入框时的启动难度。
7. 用跨模态项目把文字、图片、音乐、视频和网页串成完整作品。

## 3. 产品目标与非目标

### 3.1 产品目标

- 建立一个统一的多模态 AI 智能体入口。
- 支持学生使用平台账号，不接触第三方账号和 API Key。
- 首期完成 HTML Vibe Coding，并提供实时预览、历史记录和下载。
- 支持文字、图片、音乐、视频和语音能力的可插拔接入。
- 支持教师课程配置、课堂开关、实时辅导和学习报告。
- 支持平台默认模型池和机构自有模型池。
- 支持课程、作品、文件、知识库和学习过程的独立隔离。
- 使用允许商业二次开发的开源组件和自研业务层。

### 3.2 首期非目标

- 不直接复制 WorkBuddy 原始界面。
- 不实现 WorkBuddy 非官方登录、账号代理或接口转发。
- 不开发家长端。
- 不开发在线支付、订阅、发票和计费结算。
- 不提供学生直接编辑 HTML/CSS/JavaScript 的代码编辑器。
- 不允许学生自由配置模型、API Key、Skill、MCP 或系统提示词。
- 不承诺课程下载包可以离线调用 AI。

## 4. 用户角色与权限

### 4.1 平台管理员

负责全平台运行和安全策略：

- 创建和管理学校/机构。
- 配置平台默认模型池。
- 配置文字、图片、视频、Embedding、语音和审核服务。
- 配置 API Key、Base URL、模型名称、优先级、限流和额度。
- 配置平台级 Skill、MCP 和安全策略。
- 设置机构能力上限、数据保存上限和模型使用上限。
- 管理全平台账号、日志、备份和审计记录。
- 配置国外模型是否允许使用。
- 管理 HTML 外部资源白名单。

### 4.2 学校/机构管理员

- 管理本机构教师、班级和学生。
- 使用平台默认模型，或配置本机构自有模型池。
- 设置本机构在平台上限内的额度和数据保存周期。
- 查看本机构统计报表。
- 配置本机构知识库和课程范围。
- 批量生成、导入、冻结、启用和重置学生账号。

### 4.3 教师

- 创建课程和教学流程。
- 配置课程内容：文字、图片、视频、代码块、附件和互动任务。
- 在平台允许范围内配置班级可用功能和模型。
- 创建教学层智能体配置：名称、头像、欢迎语、教学目标和提示词补充。
- 开始、暂停、继续、结束课堂。
- 查看学生在线状态、进度、任务、预览和作品。
- 切换到学生界面进行只读查看。
- 进入辅导模式后代替学生操作。
- 审核文字、图片、视频、HTML 和作品分享。
- 查看学生 AI 使用过程和学习报告。
- 导出课程、作品和报告。

### 4.4 学生

- 使用平台分配的用户名和密码登录。
- 进入 3D AI 首页并手动选择功能入口。
- 使用被班级和教师开放的智能体。
- 通过自然语言使用 HTML Vibe Coding。
- 生成文字、图片、音乐、视频和语音内容。
- 上传允许类型的学习文件和素材。
- 查看自己的作品、历史版本、课程和成长报告。
- 下载 HTML、ZIP 作品和课程允许下载的资料。
- 创建简单个人智能体，但不能配置底层模型、工具和权限。

## 6. 核心用户流程

### 6.1 学生登录流程

1. 学生输入平台用户名和统一初始密码。
2. 系统检查账号是否启用。
3. 检查日期、星期、节次、每日时间段和教师课堂状态。
4. 检查学生所属班级是否被允许使用当前平台。
5. 登录成功后进入 3D AI 首页。
6. 登录失败时显示适合小学生理解的原因，不暴露内部策略。

### 6.2 学生批量账号流程

管理员可以：

- 设置账号前缀、数量、年级、班级和统一初始密码。
- 通过 Excel/CSV 导入姓名和班级，再自动生成平台账号。
- 设置有效日期、星期、时间段、节次和节假日例外。
- 批量启用、暂停、冻结、重置密码和导出账号卡片。

默认支持：

```text
账号：AI2026001
密码：由管理员设置
有效期：2026-09-01 至 2027-01-31
可用时间：周一至周五 14:00–18:00
```

### 6.3 3D 首页流程

学生登录后进入固定 3D 场景，场景中同时包含：

- 功能入口。
- 智能体/专家角色。
- AI 课程入口。
- 灵感案例入口。
- 我的项目和最近任务。

首期采用固定场景，不做无限地图编辑。场景支持鼠标、触控和键盘操作，并提供低性能设备降级模式。

### 6.4 HTML Vibe Coding 流程

1. 学生进入“网页创作”。
2. 左侧显示 AI 对话区。
3. 右侧显示“教程”和“预览”区域。
4. 学生用自然语言描述想生成的网页。
5. HTML 智能体生成网页和教学流程。
6. 平台执行安全检查和资源白名单检查。
7. 右侧显示实时预览。
8. 学生继续用自然语言提出修改。
9. 每次修改形成历史版本。
10. 学生可以复制、下载 HTML 或下载完整 ZIP。

学生不直接看到源码，也不能直接编辑 HTML/CSS/JavaScript。源码仅作为下载包的一部分存在。

### 6.5 教师辅导流程

1. 教师进入班级实时课堂。
2. 查看学生在线、当前功能、任务状态和预览。
3. 默认以只读方式查看学生界面。
4. 点击“进入辅导模式”后代替学生发送指令或生成内容。
5. 学生端显示“教师正在辅导你的作品”。
6. 教师退出辅导模式后恢复只读。
7. 系统记录教师查看、进入辅导和代操作的完整审计信息。

### 6.6 灵感案例流程

1. 学生进入灵感中心。
2. 系统按年级、兴趣、难度和可用能力推荐案例。
3. 学生查看示例作品、教学目标、预计时间和制作步骤。
4. 学生选择“直接开始”“换一个主题”或“跟着步骤做”。
5. 系统创建一个新的学生项目，并加载案例提示、素材和教学流程。
6. 学生可以把案例从文字继续扩展为图片、音乐、视频或网页。

### 6.7 跨模态项目流程

一个项目可以包含多个创作资产：

```text
故事文字 → 角色图片 → 主题音乐 → 动画视频 → 展示网页
```

所有资产共享项目主题、学生权限、教师课程上下文和历史记录。

## 7. 多模态智能体体系

### 7.1 通用对话智能体

- 多轮问答。
- 文件分析。
- 学习辅导。
- 总结、改写和头脑风暴。
- 根据年级控制表达难度。

### 7.2 HTML 智能体

- 自然语言生成网页。
- 自然语言修改网页。
- 生成小游戏、交互页面和科普页面。
- 生成配套教学流程。
- 保存可运行网页项目。
- 生成 HTML 和 ZIP 下载包。

### 7.3 图片智能体

- 文生图。
- 图片改图。
- 课程海报。
- 网页配图。
- 角色和场景设计。
- 素材保存和项目引用。

### 7.4 音乐智能体

- 歌曲名称和主题。
- 歌词生成或学生输入歌词。
- 音乐风格、情绪和节奏。
- 课程内容转歌曲。
- 网页和视频背景音乐。
- 试听、下载、收藏和项目引用。

### 7.5 视频智能体

- 文生视频。
- 图片转视频。
- 分镜生成。
- 科普短片。
- 课程作品视频。
- 视频配音。

面向学生提供三个入口：

- 文字变视频。
- 图片动起来。
- 从开始画面到结束画面。

视频生成采用异步任务，必须显示排队、处理中、成功、失败和重试状态。

### 7.6 专家团智能体

专家团是智能体体系中的一种高级模式，不是平台唯一模式。

示例：

```text
总控智能体
├── 需求分析智能体
├── 网页设计智能体
├── 文案智能体
├── 图片智能体
├── 编程智能体
└── 测试智能体
```

平台需要支持固定专家团模板，学生首期不能自由组合高风险专家和工具。

### 7.7 教学智能体

- 解释当前任务。
- 将任务拆成适合年级的步骤。
- 提供提示而不是直接代做。
- 根据学生行为生成下一步建议。
- 生成挑战任务和复习任务。

### 7.8 学生个人简单智能体

学生可以创建自己的简单智能体，配置：

- 名称。
- 头像。
- 用途。
- 欢迎语。
- 简单行为偏好。

学生不能配置模型、API Key、系统提示词、Skill、MCP、代码执行或外部网络权限。

### 7.9 灵感中心与案例馆

灵感中心是学生端一级入口，用于解决学生“不知道从哪里开始”的问题。案例不是静态展示图，而是可以一键转化为项目的教学模板。

每个案例至少包含：

- 案例名称。
- 适合年级。
- 创作类型。
- 难度等级。
- 预计完成时间。
- 示例作品。
- 教学目标。
- 开始提示词。
- 分步骤流程。
- 可用素材。
- 挑战任务。
- 可继续的下一种模态。

案例操作包括：

- 直接开始。
- 换一个主题。
- 跟着步骤做。
- 查看完整案例。
- 复制创作提示。
- 收藏案例。
- 分享给班级。

### 7.10 我的项目与跨模态创作链

“我的项目”是学生组织成果的核心容器。文字、图片、音乐、视频、网页和教学过程围绕一个主题形成完整作品。

```text
《小熊的森林保卫战》
├── 故事文字
├── 角色图片
├── 背景音乐
├── 动画视频
├── HTML 展示网页
├── 教学过程
├── 教师点评
└── 成长报告
```

跨模态操作包括：

- 文字一键生成图片提示。
- 图片一键进入视频工作台。
- 音乐一键作为视频或网页素材。
- 视频一键嵌入网页项目。
- 多种资产一键生成项目展示页。
- 项目一键导出为作品集。

## 8. HTML 工作台需求

### 8.1 页面布局

```text
左侧：AI 对话区
右侧：教学与预览区
右侧标签：教程 / 预览
```

不显示源码编辑器，不显示复杂模型参数。

### 8.2 教学区

支持：

- 当前步骤。
- 步骤说明。
- 图片示例。
- 视频示例。
- 代码块（只读、可复制）。
- 操作提示。
- 下一步任务。
- 挑战任务。
- 常见问题。

### 8.3 作品下载

支持下载：

- 单文件 HTML。
- 完整项目 ZIP。
- HTML 加指导文档。
- HTML、素材和指导文档组合包。

完整项目包示例：

```text
my-project.zip
├── index.html
├── style.css
├── script.js
├── assets/
└── README.md
```

### 8.4 版本记录

每次生成和修改都保存：

- 学生输入内容。
- AI 返回结果摘要。
- 预览快照。
- 时间。
- 使用的智能体。
- 使用的模型。
- 任务状态。
- 消耗额度。

学生可以查看和恢复历史版本；不能直接修改历史源码。

## 9. 教学流程和知识库

### 9.1 课程编辑器

教师可以创建：

- 文字。
- 图片。
- 视频。
- 代码块。
- 文件附件。
- 互动任务。
- 分步骤教学流程。
- 课后挑战任务。

### 9.2 AI 教学流程

支持两种来源：

1. 教师预先制作固定教程。
2. AI 根据学生的实际作品和过程自动补充教程。

最终右侧教学区显示组合后的个性化流程。

### 9.3 知识库层级

```text
平台知识库
    ↓ 可配置继承
机构知识库
    ↓ 可配置继承
课程知识库
    ↓ 可配置继承
教师知识库
    ↓ 可配置授权
学生个人资料
```

支持配置：

- 是否继承。
- 可继承范围。
- 是否允许下级补充。
- 是否允许下级覆盖。
- 学生可见范围。
- 教师可见范围。

### 9.4 课程导出

课程支持下载到本地：

- 单课包。
- 整套课程包。
- PDF。
- HTML 离线课程包。
- ZIP 课程包。

离线包支持查看文字、图片、视频、示例网页和非 AI 互动任务。AI 对话、生成和云端保存仍需联网。

## 10. API Key 与模型网关

### 10.1 模型能力

平台支持可插拔的：

- 国内文字模型。
- 国外文字模型。
- 国内图片模型。
- 国外图片模型。
- 国内视频模型。
- 国外视频模型。
- Embedding 模型。
- 语音识别模型。
- 语音合成模型。
- 内容审核模型。

### 10.2 Key 归属

支持两级模型池：

```text
平台默认模型池
    ↓
机构自有模型池（可选）
```

平台可以配置默认模型；机构可配置自己的 API Key。学生和教师都不能查看原始 Key。

### 10.3 模型配置字段

- 供应商名称。
- 能力类型。
- 国内/国外区域。
- Base URL。
- API Key 加密值。
- 模型名称。
- 优先级。
- 并发限制。
- 单日和单月额度。
- 是否启用。
- 是否允许未成年人使用。
- 是否允许跨境数据。

### 10.4 路由规则

学生不选择底层模型。平台自动根据任务类型路由，教师可在允许范围内限制模型范围。

路由依据：

- 功能类型。
- 机构配置。
- 班级配置。
- 学生额度。
- 模型区域。
- 数据敏感级别。
- 成本和并发。
- 当前健康状态。

### 10.5 国内外模型策略

- 国内模型默认启用。
- 国外模型默认关闭。
- 机构可以逐项申请和开启。
- 学生原始数据默认不能发送到国外模型。
- 如启用国外模型，必须经过脱敏、审计和权限检查。
- 国外模型网关设计为可替换模块，首期不绑定具体供应商。

## 11. 账号、课堂与权限规则

### 11.1 账号状态

- 待启用。
- 正常。
- 暂停。
- 已过期。
- 已冻结。

### 11.2 生效规则

学生必须同时满足：

```text
账号状态正常
+ 当前日期在有效期内
 + 当前星期被允许
 + 当前时间在时间段内
 + 当前节次开放
 + 教师已开课
 + 当前功能已对班级开放
```

默认时区：`Asia/Shanghai`。

### 11.3 课堂状态

- 未开课。
- 已开课。
- 已暂停。
- 已结束。
- 临时延长。

教师可以全班暂停生成、延长时间、广播通知和单独允许学生继续操作。

## 12. 作品分享与审核

### 12.1 分享范围

支持分级控制：

- 仅自己。
- 教师可见。
- 班级可见。
- 机构内可见。
- 公开链接。
- 家长查看链接。

首期默认：学生自己查看，提交后教师审核。

分享链接支持：

- 有效期。
- 是否允许下载。
- 是否允许复制。
- 一键撤销。

### 12.2 审核模式

支持两种模式：

#### 课堂模式

- 文字实时审核。
- 图片生成前后审核。
- 视频生成前后审核。
- HTML 发布前审核。
- 敏感内容自动拦截。
- 高风险内容提交教师审核。

#### 自由创作模式

- 普通内容自动放行。
- 敏感内容仍然拦截。
- 教师和管理员可以查看过程记录。

## 13. 文件、素材与存储

支持上传：

- 图片。
- PDF。
- Word。
- PPT。
- Excel。
- 音频。
- 视频。
- HTML/ZIP。

要求：

- 文件类型校验。
- 文件大小限制。
- 病毒和恶意文件扫描。
- 内容安全审核。
- AI 文件解析。
- 项目级文件隔离。
- 个人素材库。

学生生成的 HTML 外部资源默认禁止，仅允许平台管理员配置的域名白名单。

## 14. 语音能力

首期纳入：

- 语音输入。
- 语音识别。
- AI 语音回答。
- 课程朗读。
- 网页作品讲解。
- 视频配音。

语音服务通过统一模型网关接入。需要支持普通话优先，并预留其他语言扩展能力。

## 15. 学习数据与报告

系统记录：

- 登录和在线时长。
- 课程访问。
- 任务完成率。
- AI 对话次数。
- 作品版本变化。
- 使用过的智能体。
- 图片、视频和网页生成记录。
- 教师辅导记录。
- 学生提交和修改过程。
- 课堂参与度。
- 作品评价。

AI 自动生成成长报告并发送给学生和教师。报告必须：

- 基于真实过程数据。
- 使用鼓励性表达。
- 避免固定能力歧视和标签化结论。
- 支持教师查看、修改、撤回和重新生成。
- 标注“AI 生成”。

## 16. 数据保存与隔离

每个数据对象至少关联：

- `platform_id`
- `organization_id`
- `teacher_id`
- `class_id`
- `student_id`
- `workspace_id`
- `project_id`

机构可以自定义保存周期。系统支持：

- 归档。
- 批量导出。
- 批量删除。
- 删除前确认。
- 审计日志。
- 备份和恢复。

学生之间不能读取彼此的对话、文件、作品或知识库内容。

## 17. 技术架构

### 17.1 前端

- Next.js。
- React。
- TypeScript。
- React Three Fiber。
- Three.js。
- Drei。
- 响应式布局。
- 电脑端完整工作台。
- 平板端课堂适配。
- 手机端首期支持查看、审核和管理，不承诺完整创作体验。

### 17.2 后端

- Python。
- FastAPI。
- AgentScope 作为智能体运行底座。
- 模块化单体优先，避免首期过早微服务化。
- 独立模型网关模块。
- 独立任务队列模块。
- 独立沙箱预览模块。

### 17.3 数据和基础设施

- PostgreSQL：用户、机构、课程、项目、版本、日志和配置。
- Redis：缓存、会话、分布式锁、队列状态和限流。
- 腾讯云 COS：图片、视频、课程包、作品包和备份文件。
- Docker：开发、测试和生产环境一致化。
- 腾讯云 CVM 或 TKE：首期部署。
- 腾讯云 CLS：日志。
- 腾讯云监控：运行指标。

### 17.4 异步任务

图片、视频、语音、文件解析、课程导出和报告生成采用异步任务。

任务状态统一为：

```text
pending → queued → running → succeeded
                         └── failed → retrying
```

## 21. 非功能需求

### 21.1 性能

- 支持 100 人以内同时在线。
- 支持 60 人课堂同时使用。
- 文字请求应提供明确的加载和超时状态。
- 图片、视频和语音任务必须异步化。
- 高峰期使用队列和限流保护平台。

### 21.2 安全

- API Key 只在服务端保存和调用。
- API Key 加密存储并支持轮换。
- 学生不能访问系统提示词、MCP 凭证和管理员配置。
- HTML 在隔离预览环境运行。
- 外部资源使用白名单。
- 文件上传执行格式校验和安全扫描。
- 所有教师代操作、管理员配置和数据删除行为写入审计日志。

### 21.3 可维护性

- 模型供应商采用适配器模式。
- 国外模型网关可替换。
- 智能体、Skill 和 MCP 配置与业务代码解耦。
- 平台核心业务不直接绑定 Dify 或 WorkBuddy。
- 关键依赖建立第三方许可证清单。

### 21.4 商业许可证

优先采用 MIT 或 Apache-2.0 组件。重点使用：

- Three.js：MIT。
- React Three Fiber：MIT。
- Drei：MIT。
- Babylon.js：Apache-2.0。
- AgentScope：Apache-2.0。
- bolt.diy：MIT，可参考其网页生成能力。

Dify 等带有额外商业条件的项目只作为设计参考，未经授权不作为多租户商业核心。模型权重、数据集、第三方 API 和商标必须单独审核。

## 22. 验收标准

### 22.1 账号和课堂

- 管理员可以批量生成至少 60 个学生账号。
- 支持统一初始密码。
- 支持日期、星期、时间段和教师开课控制。
- 过期账号无法登录或调用 AI。
- 教师可以暂停和恢复全班生成。

### 22.2 HTML 工作台

- 学生可以只通过文字生成网页。
- 学生不能直接编辑源码。
- 右侧可以实时预览网页。
- 每次修改都形成可恢复历史版本。
- 可以下载单文件 HTML 和完整 ZIP。
- HTML 外部资源遵守白名单。

### 22.3 灵感与项目

- 学生登录后可以看到灵感案例。
- 案例可以按年级、兴趣和难度筛选。
- 学生可以一键创建案例项目。
- 一个项目可以关联文字、图片、音乐、视频和网页。
- 学生可以把一种模态的结果继续用于另一种模态。
- 教师可以创建和发布班级案例。

### 22.3 教师课堂

- 教师可以查看学生在线和任务状态。
- 教师可以切换到任意学生界面。
- 默认只读查看。
- 进入辅导模式后可以代学生发送指令。
- 所有代操作可审计。

### 22.4 模型网关

- 管理员可以配置文字、图片、视频、语音和审核模型。
- API Key 不出现在浏览器。
- 平台可以按任务自动选择模型。
- 国外模型默认关闭。
- 模型失败时可以切换备用模型。

### 22.5 课程和报告

- 教师可以编辑完整课程内容。
- 课程可以导出为 PDF、HTML 或 ZIP。
- 课程离线包可以查看资料，但不能离线调用 AI。
- 系统可以生成学生学习报告。
- 报告发送给学生和教师。

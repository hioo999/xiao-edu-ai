# 可点击 3D 创作岛设计

## 目标

将学生首页升级为可点击的 2.5D 创作入口。学生从一本打开的“AI 创作书”两岸的六个创作小屋，直接进入相应创作页面；不增加中间弹窗或二次选择。

## 场景结构

- 中心物：打开的“AI 创作书”，代表课程、知识库与学生作品的共同底座，不承载导航。
- 知识河：从书中流出的蓝色河流，连接灵感、创作与作品成长，不作为独立功能入口。
- 小屋：六个带图标与中文名称的立体小屋，分别对应 AI 对话、网页创作、图片创作、音乐创作、视频创作、智能体中心。
- 引导：悬停或键盘聚焦时，小屋轻微上浮、发光，并显示“进入创作”。

## 交互与路由

| 小屋 | 目标路由 |
| --- | --- |
| AI 对话 | `/workspace/chat` |
| 网页创作 | `/workspace/html` |
| 图片创作 | `/workspace/image` |
| 音乐创作 | `/workspace/music` |
| 视频创作 | `/workspace/video` |
| 智能体中心 | `/agents` |

- 鼠标点击、触摸点击和键盘 Enter/Space 均直接打开目标路由。
- 所有导航保留普通链接语义，便于读屏器与无 JavaScript 场景使用。
- 点击区域包含图标、名称和悬停提示，而非只有很小的 3D 模型。

## 技术边界

- 使用 CSS 2.5D 图形，不引入高体积模型文件、WebGL 兼容风险或外部版权素材。
- 场景仅在首页渲染，避免使用 Canvas，保证学校常见电脑可稳定打开。
- 尊重 `prefers-reduced-motion`；低性能设备、窄屏与不支持 WebGL 的环境显示二维入口卡片。
- 路由和儿童可操作性优先于复杂游戏化效果；不加入登录、计分或额外后端数据需求。

## 验收标准

1. 六个小屋均可见、可识别并正确跳转。
2. 悬停、键盘聚焦与按下状态有明确反馈。
3. 手机和减弱动画环境回退为现有二维入口，不影响导航。
4. 首页仍可在 Next.js 生产构建中通过，且不影响现有创作工坊页面。

# 网页创作与学生智能体

本次范围：统一六种创作入口的学生端视觉，补齐网页与学生智能体的实际操作流程。数据库继续使用 SQLite，专家团不在本次范围。

## 学生端

- 六种创作入口共用 `CreationHeader`、颜色、表单、导航和响应式规则。
- 网页支持新建、历史项目、基于已有文档连续修改、版本预览与恢复、全屏试玩、HTML 下载及指导步骤复制和下载。
- 学生智能体支持指令与模型保存、输出类型选择、历史对话、新对话、复制和下载结果。文字与网页直接保存作品；图片、音乐和视频提交平台媒体队列，展示进度、播放控件及歌词。
- 视频时长始终读取管理员配置，不接受学生覆盖。

## 网页执行边界

生成文档保留内联脚本和点击事件。服务端在所有脚本之前加入 CSP，阻止外部网络、外部脚本、嵌入页面与表单；预览使用仅开启 `allow-scripts` 的 iframe，不授予平台同源权限。下载文件保留 CSP。

每件网页作品保存自己的 HTML 文件快照，后续修改不会覆盖历史作品。审核通过的分享链接也可以预览对应 HTML。

## 学生智能体服务

`/student-agents/options` 只提供当前学生有权使用的模型、教学规则、工具与知识资料。教师和管理员通过现有后台管理这些资源。

- `/{agentId}/settings`：保存输出类型、规则、工具、知识与引擎选择。
- `/{agentId}/sessions`：创建和列出该智能体的私人对话。
- `/sessions/{sessionId}`：恢复完整对话。
- `/sessions/{sessionId}/messages`：服务端读取已保存指令、模型和上下文后执行，学生不能提供其他人的历史。

对话和设置写入 `PLATFORM_DB_PATH`。访问始终校验机构、学生和智能体归属。生成前预留积分，异常时释放；媒体任务使用已有 Worker 的成功结算和失败释放机制。

## 工具与知识配置

Skill 使用后台已启用的教学指令。知识资料仅开放平台资料、本机构组织资料和学生自己的私人资料；其他学生资料不会出现在选项中。

MCP 连接来自部署配置 `MCP_SERVER_CONNECTIONS`，不能由学生填写地址或命令。后台 MCP 条目的 ID 必须与连接 ID 一致，能力字段填写获批的工具函数名（英文逗号分隔，例如 `search,lookup`）。只显示已启用且有连接配置的服务器，执行前还会再次检查函数权限。标准模式最多进行三次外部工具调用，再返回结果。

AgentScope 模式在配置 `AGENTSCOPE_AGENT_FACTORY` 后显示。内置工厂接收学生选择的服务端模型配置以及保存的指令和教学规则，密钥不返回浏览器。需按部署文档安装 AgentScope 依赖。未启用时标准模式仍支持授权 MCP 调用。

## 运行与验证

API 使用 `PLATFORM_DB_PATH=var/platform.db python -m uvicorn apps.api.app.main:app --host 127.0.0.1 --port 8000`。媒体生成还需要项目已有的独立 Worker，并使用与 API 相同的数据库、文件目录和模型加密密钥。

本地验证命令：

```sh
python -m pytest -q
pnpm --dir apps/web test
pnpm --dir apps/web exec tsc --noEmit --incremental false
pnpm --dir apps/web test:e2e
pnpm --dir apps/web build
```

测试覆盖接口权限、SQLite 重启恢复、上下文延续、积分结算、工具权限、网页文件与分享、浏览器互动和网络隔离、播放器与歌词、桌面及手机布局。模型和工具外部服务通过注入替身验证契约；真实供应商服务的内容质量、账号额度和网络可用性仍需使用实际配置联调。

2026-10-18 验证结果：338 项 pytest、57 项前端单元测试、42 项 Playwright 浏览器测试通过，前端生产构建通过。4 项需要外部 PostgreSQL、Redis 或真实轻量模型的测试按环境条件跳过。同一网页的并发修改会串行处理，恢复版本与生成共用项目锁；学生智能体按最近使用时间恢复私人对话。

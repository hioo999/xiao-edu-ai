# 后台栏目级 UI 审查与第三阶段优化

日期：2026-10-28

## 审查范围

逐项检查了工作台、机构与账号、教学课程、课堂、作品与灵感、AI 能力中心、智能体/Skills/MCP/知识库、文件资源、生成任务、安全审核、审计、额度、家长账号和系统设置。

## 统一发现

| 栏目 | 当前情况 | 优化方向 |
| --- | --- | --- |
| 工作台 | 指标清晰，但处理入口分散 | 增加“下一步行动”聚合区，直接进入待审核作品、失败任务、未配置能力 |
| 教学运营 | 课程、课堂、账号操作较多 | 保留分组导航；表格操作按主操作、风险操作分层 |
| 内容资产 | 作品审核和资源管理容易混淆 | 作品进入审核页，文件进入资源页，页头增加明确跳转 |
| AI 能力 | 服务商配置字段密集 | 首屏突出主模型、备用模型、连接状态和调用概览，高级配置下沉 |
| AI 工具 | Agent、Skill、MCP、知识库职责相近 | 页头明确“学生可见能力 / 系统工具 / 教学知识”边界 |
| 平台治理 | 任务、审核、审计属于不同处理链 | 每个页面保留真实空状态和下一步链接 |
| 额度与成本 | 数据可读，但异常发现依赖人工 | 后续增加失败率阈值和额度不足提醒 |
| 系统设置 | 影响范围较大 | 保存后显示生效范围与时间，危险操作继续保持二次确认 |

## 本阶段已完成

- 工作台新增下一步行动中心，聚合待审核作品、失败生成任务和未配置能力。
- 服务商页新增近期调用、成功率、失败/降级概览。
- 移动端后台导航改为分组卡片布局，减少长距离横向滑动。
- 空状态、异常状态和主操作继续沿用统一后台组件与颜色语义。

## 下一步建议

1. 在所有异步列表页补充统一骨架屏，避免加载期间显示空列表。
2. 将高风险操作按钮统一放入“更多操作”，默认只保留主操作。
3. 为额度页增加“即将耗尽”和“最近失败”提醒。
4. 为课程、作品和任务列表增加批量筛选与批量操作栏。
